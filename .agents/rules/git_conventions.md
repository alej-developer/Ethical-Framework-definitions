# Normas de Control de Versiones y Mensajes de Commit

<!-- EN: Workspace rule enforcing Spanish commit messages and zero emoji policy. | ES: Regla del espacio de trabajo que impone mensajes de commit en espanol y politica de cero emojis. -->

1. **Idioma de los Mensajes de Commit**:
   - Todos los mensajes de commit en Git deben redactarse obligatoriamente en **español**.
   - Se utilizará tono infinitivo o descriptivo formal (por ejemplo: `"Implementar motor de evaluación..."`, `"Desarrollar interfaz frontend..."`, `"Actualizar documentación..."`).

2. **Política Estricta de Cero Emojis**:
   - Prohibido el uso de cualquier emoji en los mensajes de commit, descripciones de cambios o etiquetas de versiones.
